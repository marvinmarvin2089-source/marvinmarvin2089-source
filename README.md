# 🚀 Projetos em Destaque

## 🍔 MV Burguer — Aplicação Full Stack

Aplicação completa para gerenciamento e venda de produtos de uma hamburgueria, desenvolvida com **Front-End e Back-End integrados**.

### Principais funcionalidades

- 🔐 Cadastro e autenticação de usuários
- 🛡️ Autenticação e autorização com JWT
- 🍔 Catálogo de produtos e categorias
- 🛒 Carrinho de compras
- 💳 Checkout e integração de pagamentos com Stripe
- 📦 Registro e acompanhamento de pedidos
- 📊 Painel administrativo
- ✏️ Gerenciamento de produtos, categorias e pedidos
- 🖼️ Upload de imagens
- 📱 Interface responsiva para desktop e dispositivos móveis

**Tecnologias:** React, JavaScript, Node.js, Express, PostgreSQL, Sequelize, Styled-components, Material UI, Axios, JWT, Docker e Stripe.

🌐 **Projeto online:**  
[Ver MV Burguer online](https://mv-burguer-backend-front.vercel.app/)
